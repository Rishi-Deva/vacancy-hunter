# Размеченная выборка (TECHNICAL_SPEC.md, 24.2)

40 записей, собранных системой, **без оценок системы**. Владелец размечает их сам до сравнения.

1. Подготовить файл (когда извлечено достаточно записей и есть не меньше 5 разовых проектов):

   ```
   docker compose exec -T app python -m vacancy_hunter eval-sample prepare > tests/data/sample40/sample.csv
   ```

2. Открыть `sample.csv` (LibreOffice или любой редактор таблиц) и в столбце `owner_category`
   для каждой строки написать одно из трёх: `подходит`, `можно рассмотреть`, `не подходит`.
   Оценки системы в файле нет — разметка делается только по тексту.

3. Сравнить:

   ```
   docker compose exec -T app python -m vacancy_hunter eval-sample check < tests/data/sample40/sample.csv
   ```

   QLT-1: ни одна запись «подходит» не исключена правилами или фильтрами.
   QLT-2: совпадение категорий не меньше 32 из 40.

Файл `sample.csv` хранится в репозитории как постоянный эталон: проверка повторяется после
каждого изменения правил, профиля или промпта.
